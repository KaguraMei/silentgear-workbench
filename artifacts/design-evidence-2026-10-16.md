# 工业配装台视觉调整 · 2026-10-16

本轮根据用户纠正，优先改善设计和使用 Rahoo 素材。设备迁移、3D 操作与 GitHub Pages 子路径沿用用户已确认的结果；未部署站点。

## 可见变化

- 石墨黑背景和浅色切角装备铭牌，黄绿色集中用于主属性、主操作和当前选择。
- 四角面板保留 16px 外边距；面板序号、装配槽、材料卡与词条采用统一的硬边和细线。
- Rahoo 半调点阵构成展台印刷底纹，斜线用于铭牌标记，条码用于装备档案装饰；原有刻度环、HUD 弧线与等高线继续使用。参数与裁切记录见 `public/decor/SOURCES.md`。
- 桌面添加主体/工具杆等已装配部件标注，点击可选中对应部件，移动端隐藏以保证操作空间。
- Three.js 展台改为深色金属，增加 8 个实例化紧固件；装备模型及配装公式不变。
- 保留本地 HarmonyOS Sans SC 与 Monocraft WOFF2。

## 本轮检查

- `npm run typecheck`、`npm run build` 通过。
- 实际浏览器查看 1440×900、1024×768、412×839；检查铭牌、视角按钮、浮动面板和手机滚动布局，保存下方截图。
- 新部件标注点击“工具杆”“主体”后，材料库当前部位分别正确切换。
- 手机切换防具后装备名称和铭牌正常排版。
- 独立视觉审查指出点阵降低标注可读性、视角按钮偏小，已分别添加深色衬底和提高按钮尺寸/对比度。
- 默认剑渲染 8 calls、3648 triangles（原有为 7 / 3456）；新增几何为一组实例化紧固件。
- 本轮只做改动相关检查，未重新宣称完整浏览器回归或物理设备验证。
