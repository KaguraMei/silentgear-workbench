# 配装工坊验收记录

2026-10-15，生产构建，Silent Gear 数据快照 2026-10-14。

## 结果

- TypeScript 类型检查与 Vite 生产构建通过。
- Node 计算测试 18/18 通过：铁剑 6、钻石剑 7、强化黑曜石剑 14；品级、星光、护甲耐久取整、韧性、箭容量 256、配方格数、词条条件、方向性抵消、全类型有限数值等。
- Playwright 9/9 通过：桌面 Chrome 1440×900、笔记本 Edge 1024×768、Pixel 7 Chrome 触屏模拟 412×839。
- 配装、品级、星光、固定对比、词条悬浮/轻触、磨损、重置、导入导出、刷新恢复、分享链接恢复、非法文件错误处理均实际执行。
- 32 种装备逐个导入、切换、检测属性与非空装备画布。受监控流程无页面运行异常和本地资源 HTTP 错误。
- 桌面面板边距测得 16px，左右面板上下不重叠。手机文档宽度不超过视口宽度。

## 修复与视觉核查

测试发现手机模拟点击会因材料提示层捕获指针而失效。改用 Pointer Events 区分 hover 能力，并让提示层不拦截点击后，原失败操作及完整流程通过。另一导入断言误将 `<output>` 的隐式 status 角色匹配为 toast；改为精确定位 toast 后通过，导入本身没有缺陷。

检查了桌面、笔记本与手机整页截图：装备像素轮廓可见、画布铺满背景、数值与词条有清晰分区。手机允许页面纵向滚动和面板内滚动，所有配置仍可访问。截图是实际配置、磨损 50% 状态，不只是初始页。

## 性能

生产 JS 约 462 KB（gzip 110 KB），CSS 约 21 KB（gzip 5.5 KB），其中包含材料和词条数据。背景仅在尺寸变化时重绘；装备预览在配装变化时重绘；无持续动画循环。背景 DPR 上限 2，装备离屏绘制 64×64，输出 256×256；贴图以 Promise 缓存复用。

逐个切换 32 种装备的 Playwright 端到端操作中位耗时：桌面 Chrome 33ms、手机模拟 38ms；最慢约 2 秒（包含浏览器自动化等待与资源初始化）。这不是纯渲染帧时或真实移动硬件 FPS。详细原始测量见各 `*-performance.json`。

## 验证限制

没有实机 iOS / Android 或 Safari 验证，没有运行 Minecraft 逐项对照，服务器及其他模组事件可能改变实际数值。当前功能是单材料部件配置，不包含多材料合金、附魔及实战目标条件。网站默认保留拥有者私有访问权限。

使用的适用技能：Sites（构建发布）、threejs-game-director（按配装工具范围组织迭代）、threejs-game-ui-designer（浮动 UI 与触屏）、threejs-debug-profiler（绘制和性能检查）、threejs-qa-release（生产浏览器验收）。
